# Восстанавливаем распределение денег по проектам

1) В шаге АВС+D находим наибольшую прибыль - это шаг 2) 200 в ABC, 50 в D ⟶ 14+7=21  
2) Значит в проект D вносим 50 монет, в проекты ABC 200 - смотрим распределение дальше.
3) Смотрим шаг АВ+С для кол-ва монет 200 и находим наибольшую прибыль - это шаг 2) 150 в AB, 50 в C ⟶ 10+4=14 
4) В проект С вносим 50 монет, остаток идет в проекты АВ 150 монет - смотрим распределение дальше.
5) Смотрим шаг А+В для кол-ва монет 150 и находим наибольшую прибыль - это шаг 1) 150 в A, 0 в B ⟶ 10+0=10
6) В проект А вносим 150 монет, в проект В вносим 0 монет.




# Итоговое распределение средств

| Проект | Вложение | Прибыль |
|:---|---:|---:|
| A | 150 | 10 |
| B | 0 | 0 |
| C | 50 | 4 |
| D | 50 | 7 |
| **Итого** | **250** | **21** |

1) Считаем вложения А+В+С+D

2) Считаем прибыль  А+В+С+D
10+0+4+7=21 Вся прибыль сходится
