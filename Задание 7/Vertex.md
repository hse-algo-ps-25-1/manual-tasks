# Вариант 4

- \(a_n\) — количество маршрутов, заканчивающихся в вершине \(A\);
- \(b_n\) — количество маршрутов, заканчивающихся в вершине \(B\);
- \(c_n\) — количество маршрутов, заканчивающихся в вершине \(C\).

Нужно найти \(b_n\).

### 1. Составим систему уравнений

$$
\begin{cases}
a_n = b_{n-1} + c_{n-1} \\
b_n = a_{n-1} + b_{n-1} \\
c_n = a_{n-1} + b_{n-1}
\end{cases}
$$

### 2. Получим рекуррентное соотношение

Из второго и третьего уравнений видно, что \(b_n = c_n\). Равенство следует из одинаковых формул и одинаковых начальных значений.

Проверим начальные значения:
\[
 b_1 = a_0 + b_0 = 1 + 0 = 1 
\]
\[
 c_1 = a_0 + b_0 = 1 + 0 = 1 
\]

Значит \(b_1 = c_1\), и дальше по рекурсии равны все.

Тогда первое уравнение можно записать так:

\[
 a_n = 2b_{n-1} 
\]

Отсюда:

\[
 a_{n-1} = 2b_{n-2} 
\]

Подставим это во второе уравнение:

\[
 b_n = 2b_{n-2} + b_{n-1} 
\]

Перенесём всё в левую часть:

\[
 b_n - b_{n-1} - 2b_{n-2} = 0 
\]

Получили рекуррентное соотношение.

### 3. Решим характеристическое уравнение

Составим характеристическое уравнение:

\[
 \lambda^2 - \lambda - 2 = 0 
\]

Разложим на множители:

\[
 (\lambda - 2)(\lambda + 1) = 0 
\]

Получаем два корня:

\[
 \lambda_1 = 2, \quad \lambda_2 = -1 
\]

Корни разные, поэтому общее решение имеет вид:

\[
 b_n = A_1 \cdot 2^n + A_2 \cdot (-1)^n 
\]

### 4. Найдём начальные условия

При \(n = 1\) есть один маршрут из \(A\) в \(B\):

\[
 A \to B 
\]

Значит, \(b_1 = 1\).

При \(n = 2\) количество маршрутов:

\[
 b_2 = a_1 + b_1 = 0 + 1 = 1 
\]

Получаем начальные условия:

\[
 b_1 = 1, \quad b_2 = 1 
\]

Подставим их в общее решение:

$$
\begin{cases}
1 = 2A_1 - A_2 \\
1 = 4A_1 + A_2
\end{cases}
$$

Сложим два уравнения:

\[
 2 = 6A_1 \implies A_1 = \frac{1}{3} 
\]

Теперь найдём \(A_2\):

\[
 1 = 2 \cdot \frac{1}{3} - A_2 \implies A_2 = -\frac{1}{3} 
\]

### 5. Запишем общую формулу

Подставим найденные значения коэффициентов:

\[
 b_n = \frac{1}{3} \cdot 2^n - \frac{1}{3} \cdot (-1)^n 
\]

Итоговая формула:

\[
 b_n = \frac{2^n - (-1)^n}{3} 
\]

**Ответ:** количество маршрутов длины \(n\) из вершины \(A\) в вершину \(B\) равно \(\frac{2^n - (-1)^n}{3}\).

## Проверка

Проверка для \(n = 3\) и \(n = 4\).

Для этого сначала воспользуемся рекуррентным соотношением:

\[
 b_n = b_{n-1} + 2b_{n-2} 
\]

При \(n = 3\):

\[
 b_3 = b_2 + 2b_1 = 1 + 2 \cdot 1 = 3 
\]

При \(n = 4\):

\[
 b_4 = b_3 + 2b_2 = 3 + 2 \cdot 1 = 5 
\]

Проверка по общей формуле.

При \(n = 3\):

\[
 b_3 = \frac{2^3 - (-1)^3}{3} = \frac{8 + 1}{3} = 3 
\]

При \(n = 4\):

\[
 b_4 = \frac{2^4 - (-1)^4}{3} = \frac{16 - 1}{3} = 5 
\]
